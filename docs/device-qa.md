# iOS·Android 실기기 검수

Android APK 또는 iOS 개발 빌드를 설치하고 OS 버전, 기기 모델, 앱 커밋을 기록해요. 각 플랫폼에서 같은 네 시나리오를 실행해요. 에뮬레이터와 실기기 결과는 따로 기록해요.

| 시나리오 | 진행 | 기대 결과 | Android 실기기 | iOS 실기기 |
|---|---|---|---|---|
| 작은 세로 화면 | 공연을 시작하고 앞줄·뒷줄 볼륨을 각각 조절한 뒤 신호를 예약해요. | 한 구역을 조작할 때 다른 구역의 슬라이더 값이 바뀌지 않아요. 구역명과 신호 버튼을 구별할 수 있어요. | 미확인 | 미확인 |
| 큰 글자 | 시스템 글자 크기를 크게 설정하고 공연·결과 화면을 열어요. | 카드가 필요하면 세로로 전환되고, 끝까지 스크롤해 모든 버튼과 기록을 읽고 누를 수 있어요. | 미확인 | 미확인 |
| 무음·오프라인 | 비행기 모드를 켜고 게임 음량 0, 진동 끔으로 설정해요. 공연을 완주하고 후렴을 다시 열어요. | 소리와 진동 없이 관객 반응·박자·예고를 읽을 수 있어요. 결과와 재도전이 열리고, 앱 재실행 뒤 설정과 확정 기록이 유지돼요. | 미확인 | 미확인 |
| 일시정지·백그라운드 복귀 | 신호 예약 직후 일시정지하고 기다린 뒤 이어 해요. 홈으로 나갔다가 앱을 다시 열어요. | 정지 중에는 시간과 점수가 진행되지 않아요. 복귀 뒤 구역 볼륨과 예약 상태를 유지하고 같은 위치에서 진행해요. | 미확인 | 미확인 |

결과는 통과, 실패, 미확인으로 표시해요. 실패 시 기기 모델, 화면 크기나 글자 설정, 단계, 예상 동작, 실제 동작을 남겨요. 임시로 바꾼 기기 설정은 검수 후 복원해요.

## Android 에뮬레이터 확인 기록

Android 15(API 35), sdk gphone64 x86_64, 디버그 APK에서 확인했어요. 아래 결과는 실기기 열에 집계하지 않아요.

| 시나리오 | 확인한 내용 | 보완 확인 |
|---|---|---|
| 작은 세로 화면 | 320×640에서 스크롤 후 두 카드를 조작했어요. 앞줄 55%, 뒷줄 48%가 각각 표시됐어요. | 신호 예약과 떼창 전환은 320×640 위젯 테스트에서 확인했어요. |
| 큰 글자 | 320×640, 시스템 글자 크기 1.8배에서 두 카드가 세로로 전환되고, 숙련 후렴 결과와 재도전 버튼이 스크롤로 보였어요. | 실기기의 최대 글자 크기는 기기별로 검수해요. |
| 무음·오프라인 | 비행기 모드, Wi-Fi 끔, 게임 음량 0, 진동 끔으로 공연을 완주했어요. 결과에서 후렴 3을 열어 앞줄 50%, 뒷줄 51%가 복원됐어요. 앱 재실행 후 설정과 일반 기록 35/90점을 확인했고 숙련 점수 7/30점이 별도 저장됐어요. | 실제 게임 음악의 음량 변화는 음악 연동 후 검사해요. |
| 일시정지·백그라운드 복귀 | 일시정지 팝업을 띄운 채 홈으로 나갔다 돌아왔을 때 볼륨과 관객 상태가 유지됐고, 이어 하기 후 공연을 완주했어요. | 신호 예약 직후 일시정지와 공연 시계 정지는 위젯 테스트에서 확인했어요. |

이 작업 환경에는 Android 에뮬레이터만 연결되어 있었어요. iOS 빌드·실행 환경과 Android·iOS 실기기가 확보되면 표의 미확인 항목을 실행해요.

## 관객·오디오 적용 후 추가 검수

- Android 15 에뮬레이터 320×640, 게임 음량 0에서 두 카드와 객석이 같은 화면에 있는 상태로 앞줄 귀 막기 및 양쪽 떼창을 재현했어요. [귀 막기](art/ui/compact-crowd-cover-ears.png) · [떼창](art/ui/compact-crowd-singalong.png)
- 별도 Android 15 에뮬레이터에서 음량 기본값으로 실행하고 AudioFlinger의 앱 트랙을 확인했어요. 공연 중 활성, 일시정지 시 비활성, 이어 하기 후 다시 활성 상태였어요.
- 같은 빌드에서 마지막 후렴 숙련 도전을 열어 시작 볼륨 50%·40%와 발전기 예고를 확인했고 활성 오디오 트랙이 생성됐어요. 74초 오프셋과 각 효과음의 사건 시각은 공연 모델 테스트로 확인했어요.
- 애니메이션과 오디오가 연결된 이 빌드의 iOS 및 물리 Android 기기 검수는 미확인이에요.

## iPhone 화면 회귀 검수

- iOS 위젯 테스트에서 위아래 안전 영역이 있는 390×740 세로 화면과 양옆·아래 안전 영역이 있는 852×393 가로 화면을 재현했어요. 공연 시작 안내를 읽고, 스크롤 없이 두 슬라이더를 사용할 수 있으며, 공연 종료 후 결과를 열 수 있는지 확인했어요.
- iPhone 실기기에서는 TestFlight 빌드로 같은 동작을 확인해요.
